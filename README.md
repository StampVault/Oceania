# StampVault: Oceania

**This is part of the stamp data used by StampVault: [GitHub](https://github.com/StampVault/StampVault.git) / [GitLab](https://gitlab.com/StampVault/StampVault.git).**

This repository contains the data for Oceania. To use this data with StampVault, clone this repository into the `stamps/data` subdirectory of StampVault.

See the documentation of StampVault for more information.
